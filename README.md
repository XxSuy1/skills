# skills

我的 Claude / TeleAgent Skill 合集。每个文件夹是一个独立的 skill，根目录有 `SKILL.md`。

| Skill | 说明 |
|---|---|
| [paper-cut-video](paper-cut-video/) | 「纸剪定格」风格视频制作：天蓝底纸、手剪纸片、和纸胶带、12 格/秒定格、合成配乐音效，一条命令出 1080p MP4。含风格规范、引擎接口说明和可直接运行的最小模板（`template/`）。 |

## 使用
把某个 skill 文件夹复制到 `~/.claude/skills/`（所有项目可用）或项目的 `.claude/skills/`（仅该项目）即可。
